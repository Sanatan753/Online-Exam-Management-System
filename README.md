## 💡 Usage Workflow

1. **Admin Login:** Log in with administrator credentials to set up subjects, add questions to the question bank, and publish exam schedules.
2. **Student Registration/Login:** Students log in using their credentials to view active and upcoming exams.
3. **Taking the Exam:** Start the test within the allocated time window. The automated timer handles submission upon expiration.
4. **Evaluation:** Admins review performance analytics and generate reports.
